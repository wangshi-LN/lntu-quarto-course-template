# 辽宁工程技术大学课程模板

面向辽宁工程技术大学课程教学的 Quarto / Reveal.js HTML 课件模板。使用 Markdown / Quarto 编辑内容，保留学校标识、校园插画、浅青绿色与暖白配色，以及现有 4∶3 页面版式。本项目为个人维护的课程模板，并非学校官方发布的模板。

提供封面、章节目录、正文、图文、媒体与结束页，支持页面涂鸦、黑板和 Speaker View 双窗口笔迹同步。项目以本校课程使用为目标，支持为不同课程创建独立副本。模板源码以 v1.4 为基线继续维护，最近功能更新见 [验证记录](验证记录.md)。

## 使用环境

### 下载后直接播放

下载 [v1.5.0 完整课件包（ZIP）](https://github.com/wangshi-LN/lntu-quarto-course-template/releases/download/v1.5.0/lntu-quarto-course-template-v1.5.0.zip)，将整个 ZIP 解压到普通文件夹，然后双击 `打开课件.cmd` 或 `course.html`。查看全部版式时，双击 `查看版式.cmd` 或 `layouts.html`。无需运行生成脚本，也无需安装 Quarto、Python、R 或 Jupyter。

包内同时包含 HTML、配套资源、字体、图片、本地示例视频、可编辑源码和许可说明。请保留解压后的目录结构，不要只取出 HTML，也不要在 ZIP 预览窗口里直接打开。网络视频需要联网；按 `S` 打开演讲者模式时需允许浏览器弹窗。

GitHub 自动提供的 `Source code (zip)` / `Source code (tar.gz)` 是源码归档；直接播放请下载上面命名的完整课件包。完整包中的课件为模板示例，不包含三讲学术写作课程内容。包内附有 SHA-256 文件清单，Release 同时提供 ZIP 校验值。

### 编辑和生成

- 编辑和生成：已验证 Windows、PowerShell、Quarto 1.10.18；不需要 R 或 Jupyter。
- 播放：生成后直接打开 HTML，播放电脑不需要安装 Quarto；须同时携带相应资源目录。
- 涂鸦双窗口同步：已验证 Chromium 155.0.8059.40 的本地 `file://` 方式，详见下文。
- 可选本地服务器：已有 Python 时可运行 `serve.py`。

## 版本维护

本目录是唯一模板工作目录。Git 从 v1.4 开始记录源文件和必要资源；日常修改在本目录提交，正式版本使用 Git 标签，不再复制整套模板建立版本目录。制作其他课程仍使用 `新建课程.cmd` 创建独立课程副本。

Git 历史从 v1.4 源码导入开始。维护者另有 v1.0 至 v1.4 的本地历史归档，该归档不属于本仓库，也不影响下载后的生成和使用。

常用命令：

```powershell
git status --short
git log --oneline --decorate
git diff
```

完成一组修改并检查后，提交对应源文件；正式发布时添加版本标签。HTML、渲染资源目录和缓存保留在本地，不纳入 Git，修改源文件后运行 `生成课件.cmd` 更新。需要分发时导出包含 HTML、资源和素材的完整包；仅导出 Git 源码不能直接替代可播放的课件包。

维护者制作分发包时，先运行 `build.ps1 -Target all`，再运行 `python scripts/package-release.py --version 1.5.0 --date 2026-10-14 --output-dir <已有输出目录>`。脚本要求源码已提交，读取当前提交的源码并打入两份已生成的 HTML 及完整资源目录，校验 ZIP 内各文件的 SHA-256；不会将生成文件纳入 Git。

## 最短使用流程

1. 下载或克隆本仓库。双击 `新建课程.cmd`，输入新课程文件夹完整路径，保留模板目录用于后续维护。
2. 在新目录编辑 `course.yml`：课程名称、副标题、授课教师和校徽路径。首页与尾页背景使用模板固定素材，无须按课程修改。
3. 编辑 `course.qmd`：替换示例内容。从 `layouts.qmd` 复制所需版式，每页从 `##` 开始，到下一页 `##` 之前结束。
4. 双击 `生成课件.cmd`。需要本机已有 Quarto；制作此模板时为1.10.18，无须R或Jupyter。
5. 双击 `打开课件.cmd` 播放正式课件，或 `查看版式.cmd` 查看全部页型。

命令行也可以这样用（在模板目录中执行；目标目录必须不存在）：

```powershell
.\New-Course.ps1 -Destination 'D:\我的课程\课件-信息论-2026-09-24'
```

创建副本复制可编辑源文件、必要资源及许可说明，不复制已经生成的HTML、缓存和验证记录。进入新目录后先生成。脚本不会覆盖已有目标目录；双击脚本仅对当前进程使用执行策略参数，不更改系统执行策略。

## 三个常用入口

| 文件 | 用途 |
|---|---|
| `course.yml` | 集中修改课程名、副标题、教师和校徽；首页、尾页背景固定使用模板素材 |
| `course.qmd` → `course.html` | 新课程的6页起步稿：封面、第一章目录、正文、第二章目录、正文、结束 |
| `layouts.qmd` → `layouts.html` | 15页全部版式示范，包含三组目录与十种内容页 |

内容版式：单栏文字、双栏文字、双栏对比加总结、四块对比、三块对比、卡片网格、单张图片、图文混排、B站嵌入视频、本地视频。示例文案只解释布局，不属于任何课程的正式内容。

正文中的 `data-chapter-title="第一章"` 决定右下角章节名称和导航配色；教师来自 `course.yml`，不需要逐页修改。目录中的标题、说明和目标链接使用 Markdown 在 QMD 中维护，无须编写 HTML。新增页面务必更改 `#页面ID`，目录链接使用 `#/页面ID`。

底栏左右各占50%：左侧放导航，右侧放章节与教师信息；两部分分别以各自底栏区域独立垂直居中，布局与定位不依赖页脚文字尺寸。

每章开始复制一张目录页，只需调整页面 ID、`data-chapter-title` 与 `current`：

```markdown
## 内容目录 {#contents-1 .body-header-preview .contents-page data-chapter-title="第一章"}

::: {.course-toc current="1"}
- [第一章](#/first-content "在这里填写章节说明")
- [第二章](#/second-content "在这里填写章节说明")
:::
```

列表顺序自动生成 `01`、`02` 等编号；`current="1"` 表示突出第 1 项，第二章改为 `current="2"`，以此类推。省略 `current` 时不突出任何项。方括号内填写章节标题，链接指向该章正文首页，双引号内填写显示在标题下方的章节说明（可省略）。每一项仅写一个链接，不在目录块内混写其他段落或嵌套列表。

`theme/course-config.lua` 将这种 Markdown 输入转换为已有目录结构，继续使用原有目录样式与导航。转换仅接受上述目录块和链接条目形状，其他内容保留原样；既有 HTML 目录仍兼容。

可将 `subtitle` 设置为空字符串。`pagetitle` 是QMD顶部的浏览器标签标题，可按课程自行修改。标题过长时缩短或合理换行，不能通过缩字挤满封面。

## 播放与分发

默认是**HTML＋资源文件夹**，启用涂鸦。播放电脑无须安装Quarto，使用现代Edge或Chrome即可。最省心的携带方法是复制整个课程文件夹。精简分发时须同时携带：

- `course.html`
- `course_files/`（Quarto生成的播放器、涂鸦、样式等文件）
- `assets/`（字体、图片和视频）

三者保持相对位置。如果在QMD中新增其他目录的资源，也必须一同携带。`layouts.html` 对应 `layouts_files/`。普通本地图片、字体和MP4可离线使用；B站播放器需要联网，平台可能限制嵌入播放，应在授课电脑预先检查。

双击HTML可以播放。如需本地HTTP播放、视频分段定位或浏览器对本地文件有限制，可在已安装Python的电脑运行：

```powershell
python serve.py
```

访问 `http://127.0.0.1:18768/course.html` 或 `http://127.0.0.1:18768/layouts.html`；终端需保持运行，Ctrl+C停止。服务器仅绑定本机，支持本地视频Range请求。端口被占用时修改 `serve.py` 末尾两处端口。

## 涂鸦

`C` 切换页面批注，`B` 切换黑板；也可使用右上角控件。**删除涂鸦**清除当前页当前画布，**导出涂鸦**导出整份课件笔迹JSON。关闭或刷新前导出，切勿把浏览器状态当作可靠备份。导出后在下载目录检查文件实际存在。

需要预载保存的笔迹时，将JSON放到课程目录，修改 `_quarto.yml`：

```yaml
    chalkboard:
      src: chalkboard.json
```

默认 `chalk-effect: 0.000000000000001`，chalkboard 的粉笔笔迹显示为不透明实线，实际不会产生可见的粉笔擦痕。所用插件会忽略字面值 `0` 并回退至默认值 `1`，因此使用极小正数关闭效果。要恢复粉笔质感，可将 `_quarto.yml` 中该值调高，范围为 `0.0` 到 `1.0`。

笔迹与幻灯顺序相关，重排页面后必须复查对应关系。其他电脑需要带上这个JSON。以浏览器实际下载和重载结果为准。

### Speaker View 涂鸦同步（2026-10-14）

直接打开 `course.html` 或 `layouts.html`，按 `S` 打开演讲者窗口。在 Speaker View 的“当前页”区域按 `C` 或点击批注按钮后书写，笔迹、擦除和删除操作会同步到投影主窗口；从主窗口书写也会反向同步。`C` 只控制所在窗口是否接收书写输入，`B` 的黑板开关和黑板切换会同步。“下一页预览”不参与笔迹同步。

主窗口保持打开时，关闭并重新按 `S` 打开演讲者窗口，可恢复已有页面笔迹、黑板笔迹和当前黑板。允许浏览器打开演讲者弹窗。刷新或关闭主窗口前仍需导出涂鸦 JSON；窗口同步不提供跨次打开的自动保存。

实现位于 `theme/chalkboard-sync.html`，由 `_quarto.yml` 引入，生成时会自动进入 HTML；不需要修改 Quarto 安装目录或生成的插件文件，也不需要启动服务器。画笔、橡皮擦和坐标按课件尺寸缩放，适配不同大小的两个窗口。单文件导出仍关闭涂鸦。

当前验证环境为 Quarto 1.10.18、其内置 RevealChalkboard 2.3.3，以及 Chromium 155.0.8059.40 的 `file://` 双窗口。依赖该插件的 `welcome`、`broadcast`、`received`、`seekplayback` 事件协议；更换 Quarto/插件版本后应重跑相关检查。验证记录见 `验证记录.md`；`scripts/test-chalkboard-sync.js` 是 Playwright `browser_run_code_unsafe` 的函数文件，先打开本模板的本地 `course.html`，再以 `filename` 调用。测试会刷新该测试页并关闭同一测试浏览器上下文的其他窗口，应使用专用测试上下文。

## 导出单文件

```powershell
.\build.ps1 -Target single
```

生成 `course-single.html`，关闭涂鸦，嵌入默认字体与本地示例素材，可单独复制播放。网络视频仍联网；明确设置 `data-external="1"` 的自定义资源不会打包。长视频和大量大图片推荐继续采用默认资源文件夹形式。此操作不覆盖默认 `course.html`。

其他生成命令：`.\build.ps1 -Target course` 只生成正式课件；`-Target layouts` 只生成样例；`-Target all` 生成两份默认课件。不要在同一目录同时运行多个渲染进程。

## 素材与样式

字体原件与许可证位于 `assets/fonts/`，默认按相对路径加载，不要求系统安装。页脚楷体沿用系统字体，其他系统缺少楷体时会回退。学校素材源于已确认模板，并非学校官方发布的模板。结束页的书法字在图片里，修改字样必须更换图片。素材历史说明见 `素材来源.md`，其中旧文件名和旧路径属于来源记录，不是本包的生成依赖。

首页固定使用 `assets/lntu-illustrated-background-4x3.png`，尾页固定使用 `assets/lntu-ending-artwork-4x3.png`。课程副本编辑 `course.yml` 时无需填写或调整这两张背景图；模板生成流程会继续携带它们。

字体定义在 `theme/fonts.html`；公共样式在 `theme/course-theme.scss`，已确认的4∶3具体版式在 `theme/body-header-preview.scss`。沿用既有类名以保持兼容。标题48pt、封面副标题40pt、三级标题32pt、正文24pt，内容超量时拆页。

Markdown 单星号 `*文字*` 显示为 28pt、正体（非斜体）。

`BASELINE.json` 记录历史基线及原始文件校验值。本地已有的 `SHA256SUMS.txt` 属于历史交付记录，不纳入源码仓库，也不用于断言当前工作树文件未变化。模板更新继续在唯一维护目录使用 Git 提交和版本标签管理；已制作的课程副本按需单独更新。
